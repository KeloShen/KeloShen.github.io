# workshop: 工作室 | 项目与技能
> 火花四溅，焊锡的烟雾缭绕。工作台上的屏幕里，一个 AI 智能体正在推理一笔银行交易是否合理；旁边是一台看起来很像你现在所在这个终端的电脑。地上摊着一个用旧了的工具箱。

我做端到端的大模型应用：用 LangChain4j 和 Spring Boot 编排智能体，用 Vue 3 + TypeScript 写前端，再用 Docker、Kubernetes 和 Jenkins 把它们稳定地部署起来。

## agent: 合规智能体 | 智能体, 银行, 汇丰, 反洗钱, 毕设项目, 原型a
项目 · 银行客户交易记录合理性分析系统
与汇丰科技合作 · 2025.12 – 2026.04 · 本科毕业设计
做什么：面向银行反洗钱与合规审查的智能分析系统。输入客户基本信息和交易流水，由大模型智能体判定每笔交易是否合理，给出结论、理由和证据；无法确定的高风险案例自动转人工复核。
我做了什么：
  · 独立设计并实现基于 LangChain4j + Spring Boot 3 的后端架构，持久化多轮对话记忆，支持同一任务内的追问
  · 多智能体编排流水线：检测 → 复审 → 需人工澄清 → 终局裁决，低置信度自动转人工（Human-in-the-Loop）
  · 可插拔的 Skill 库：每条检测规则封装为独立 Skill（规则 + 参数 + 参考知识），通过"规则预选 + 语义匹配"按需加载，实现渐进式披露和 RAG 式检索
  · Function Calling：由模型自主决定激活哪些 Skill，而不是一次性注入全部内容
  · 用户反馈闭环：纠错信息自动提炼成经验并沉淀，后续分析动态引用，实现智能体自学习
  · 分层思维链（CoT）+ 反幻觉约束的提示词工程，版本化迭代以提升准确率
  · 前端使用 Vue 3 + TypeScript + Tailwind CSS 4
